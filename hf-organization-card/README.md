  <h1>TSC-FM Benchmark</h1>
  <p>Evaluation resources for foundation models in time series classification.</p>
</div>

TSC-FM provides an official leaderboard, dataset profile, capability analysis, evaluation protocol, and a maintained submission workflow. The Hugging Face organization is the public model-community entry point; the canonical benchmark and its submissions remain on the official site.

## Start here

- **[Visit the official benchmark](https://tsc-fm.dmirlab.com/)**
- **[Open the live Hugging Face overview](https://huggingface.co/spaces/TSC-FM/benchmark)**
- [Explore the full leaderboard](https://tsc-fm.dmirlab.com/leaderboard)
- [Read the evaluation protocol](https://tsc-fm.dmirlab.com/evaluation)
- [Submit benchmark results](https://tsc-fm.dmirlab.com/submit)

## Maintainers

TSC-FM is maintained by [DMIR Lab](https://dmir.gdut.edu.cn/). For benchmark questions, contact [Juntao Fang](mailto:fangjuntao1@mails.gdut.edu.cn).
