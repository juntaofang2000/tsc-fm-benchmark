TSC-FM provides an official leaderboard, dataset profile, capability analysis, evaluation protocol, and a maintained submission workflow. The Hugging Face organization is the public model-community entry point; the canonical benchmark and its submissions remain on the official site.

## Start here

- **[Visit the official time series classification benchmark](https://tsc-fm.dmirlab.com/)**
- **[Open the live Hugging Face overview](https://huggingface.co/spaces/TSC-FM/benchmark)**
- [Explore the time series classification leaderboard](https://tsc-fm.dmirlab.com/leaderboard)
- [Compare foundation models for time series classification](https://tsc-fm.dmirlab.com/methods)
- [Read the evaluation protocol](https://tsc-fm.dmirlab.com/evaluation)
- [Submit a model for evaluation](https://tsc-fm.dmirlab.com/submit)

## Release and maintenance

TSC-FM is jointly released by [DMIR Lab](https://dmir.gdut.edu.cn/) and Huawei Noah’s Ark Lab.

Maintained by [Juntao Fang](https://juntaofang2000.github.io/). For benchmark questions, contact [fangjuntao1@mails.gdut.edu.cn](mailto:fangjuntao1@mails.gdut.edu.cn).
